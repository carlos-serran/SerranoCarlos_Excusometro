Detector Catálogo Protocolo

Que hacemos?

Analizamos excusas academicas mediante tecnologia poco fiable

  • Se me borro solo
  • Se lo comio el perro
  • Github no funcionaba
  • En mi ordenador si funcionaba
  • No sabia que era para hoy

Como funciona?

Recibimos la excusa, la estudiamos y emitimos un veredicto

  1. Recibir una excusa
  2. Comrpobar su nivel de drama
  3. Buscar contradicciones sospechosas
  4. Calcular su credibilidad
  5. Emitir un veredicto final

Estado del sistema

Sistema preparado para recibir excusas

  • Funcionando correctamente defectuoso
    1. Se reciben solo las excusas mas increibles
    2. Lo hacen de forma desordenada
  • Las excusas recibidas estan llenas equivocadamente
  • Credibilidad de las excusas poco fiable
  • Cantidad de excusas superan el almacenamiento maximo
  • Todas las excusas tienen un registro exitoso
